# Praktická Cvičení s AI Nástroji pro Programátory

Tato cvičení jsou navržena tak, abyste si prakticky vyzkoušeli, jak vám AI asistenti (jako ChatGPT, Gemini, Claude, atd.) mohou pomoci v různých fázích programování. Pro každé cvičení máte připravené soubory v odpovídající složce.

---

Jeden z možných řešení najdete v [solution branch](https://github.com/HackingCZE/PPRO-ai-nastroje-pro-programatory/tree/solution) .

---

## Příklad 1: Vylepšení vzhledu (To-Do List)

**Cíl:** Vylepšit vizuální podobu jednoduché webové aplikace pomocí AI.

**Soubory:**

- `/priklad1-todo/index.html`
- `/priklad1-todo/style.css`
- `/priklad1-todo/script.js`

**Postup:**

1.  Otevřete si soubor `index.html` v prohlížeči. Uvidíte velmi jednoduchý a nepříliš hezký To-Do list.
2.  Otevřete si soubor `style.css`. Tento soubor obsahuje základní styly, které je potřeba vylepšit.
3.  Zkopírujte obsah souboru `style.css` a vložte ho do chatu s vaším oblíbeným AI asistentem.
4.  **Zadejte AI asistentovi následující úkol:**

    > "Ahoj, tady je CSS kód pro můj To-Do list. Vzhled je velmi jednoduchý a nudný. Můžeš mi prosím tento CSS kód kompletně přepracovat, aby aplikace vypadala moderně a profesionálně? Použij nějakou hezkou barevnou paletu, lepší fonty, přidej stíny a udělej layout přehlednější. Chci, aby to byl opravdu velký vizuální skok."

5.  Vezměte vygenerovaný CSS kód od AI a nahraďte jím původní obsah souboru `style.css`.
6.  Obnovte stránku `index.html` v prohlížeči a podívejte se na výsledek.

## Příklad 2: Hledání a oprava chyb (Kalkulačka)

**Cíl:** Najít a opravit logické chyby v Python skriptu s pomocí AI.

**Soubor:**

- `/priklad2-kalkulacka/kalkulacka.py`

**Postup:**

1.  Prohlédněte si soubor `kalkulacka.py`. Jedná se o jednoduchou kalkulačku, která má ale dvě logické chyby.
2.  Zkuste skript spustit a otestovat jeho funkčnost. Zkuste například dělit nulou nebo vypočítat průměr ze 3 čísel. Uvidíte, že program buď spadne, nebo vrátí nesprávný výsledek.
3.  Zkopírujte celý obsah souboru `kalkulacka.py` a vložte ho do chatu s AI asistentem.
4.  **Zadejte AI asistentovi následující úkol:**

    > "Ahoj, v tomto Python skriptu pro kalkulačku jsou nějaké chyby. Když se pokusím dělit nulou, program spadne. A když chci vypočítat průměr, vrací to nesmyslné číslo. Můžeš mi prosím najít všechny chyby, opravit je a vysvětlit mi, v čem byl problém?"

5.  Projděte si odpověď od AI. Aplikujte navržené opravy do souboru `kalkulacka.py`.
6.  Znovu skript spusťte a otestujte, zda jsou chyby opraveny.

## Příklad 3: Code Review (Aplikace Počasí)

**Cíl:** Vylepšit kvalitu existujícího kódu na základě doporučení od AI.

**Soubor:**

- `/priklad3-pocasi/pocasi.py`

**Postup:**

1.  Otevřete si soubor `pocasi.py`. Tento skript funguje, ale jeho kód je neefektivní, opakuje se a není dobře strukturovaný.
2.  Zkopírujte celý obsah souboru a vložte ho do chatu s AI asistentem.
3.  **Zadejte AI asistentovi následující úkol:**

    > "Ahoj, můžeš mi prosím udělat code review tohoto Python skriptu? Funguje, ale mám pocit, že by se dal napsat mnohem lépe. Zaměř se na duplicitní kód, efektivitu a celkovou čitelnost. Navrhni mi prosím vylepšenou verzi a vysvětli, jaké změny jsi provedl a proč."

4.  Analyzujte návrhy od AI. Všimněte si, jak AI může zjednodušit logiku a odstranit opakující se části kódu.
5.  Nahraďte původní kód vylepšenou verzí od AI a ověřte, že stále funguje správně.

## Příklad 4: Generování dokumentace (Správce Kontaktů)

**Cíl:** Naučit se automaticky generovat dokumentaci pro existující kód.

**Soubor:**

- `/priklad4-kontakty/kontakty.py`

**Postup:**

1.  Prohlédněte si soubor `kontakty.py`. Jedná se o jednoduchý skript pro správu kontaktů, který je plně funkční, ale neobsahuje žádnou dokumentaci (docstringy, komentáře).
2.  Zkopírujte celý obsah souboru a vložte ho do chatu s AI asistentem.
3.  **Zadejte AI asistentovi následující úkol:**

    > "Ahoj, tady je můj Python skript pro správu kontaktů. Potřeboval bych k němu vygenerovat kompletní dokumentaci. Přidej prosím standardní Python docstringy ke všem třídám a metodám. Vysvětli, co jednotlivé části dělají, jaké přijímají parametry a co vracejí. Můžeš přidat i nějaké řádkové komentáře na složitější místa, pokud je najdeš."

4.  Vezměte kód doplněný o dokumentaci a nahraďte jím původní obsah souboru `kontakty.py`.
5.  Projděte si vygenerovanou dokumentaci a zhodnoťte její kvalitu a srozumitelnost.
